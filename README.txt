SAFFRON & SAGE — CATERING WEBSITE STARTER

FILES
- index.html: Home page with hero, services, menu feature, testimonials/CTA
- login.html: Login UI
- signup.html: Sign-up UI with basic front-end validation
- booking.html: Event enquiry form with confirmation state
- style.css: Responsive styling, layout, typography, colors, mobile navigation
- script.js: Mobile menu and front-end form demo behavior

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Install/use the Live Server extension, then right-click index.html > Open with Live Server.
   Alternatively, open index.html directly in a browser.
4. Use the navigation links to visit Login, Sign Up, and Book an Event.

IMPORTANT
This is a front-end prototype. Login and signup do not authenticate real users, and booking enquiries are not sent to a business. For production, connect a secure backend/database and authentication system, plus an email/booking notification service. Do not store real passwords in localStorage. Photos load from Unsplash URLs and Google Fonts load online.

Customize the brand name, contact details, menus, pricing, service areas, and photos before publishing.
